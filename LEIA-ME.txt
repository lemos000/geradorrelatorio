=====================================================
   SISTEMA DE AUDITORIA HOTELEIRA BI - ESCRIPTES
=====================================================

COMO USAR:
1. Certifique-se de que o Python está instalado.
2. Instale as dependências (apenas na primeira vez):
   Abra o terminal e digite:
   pip install -r requirements.txt

3. Execute o programa:
   python main.py

4. Na tela:
   - Selecione o arquivo de "Check-outs" no primeiro botão.
   - Selecione o arquivo de "Reservas Emitidas" no segundo botão.
   - Clique em "INICIAR PROCESSAMENTO".

5. Resultados:
   - Relatorio_Auditoria.xlsx (Planilha detalhada com 3 abas)
   - Relatorio_Apresentacao.pptx (Slides com tabelas visuais)

Os arquivos serão salvos nesta mesma pasta.
